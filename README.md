-CommerceDBTrigger

Esse projeto se trata de um modelo de banco de dados relacional para um sistema de comércio, com foco em auditoria automática por meio de triggers SQL. Ele simula um ambiente com as tabelas mais comuns em um sistema comercial — como produtos, categorias e usuários — e utiliza gatilhos para monitorar alterações.

------------------------------------

-Objetivo

Demonstrar a aplicação de triggers em SQL para rastrear operações de INSERT, UPDATE e DELETE nas principais tabelas de um banco de dados de comércio.

------------------------------------

-Tecnologias utilizadas

- PostgreSQL
- pgAdmin 4
- SQL puro

------------------------------------

-Funcionalidades

- Estruturação completa de um banco de dados de comércio
- Criação de triggers para:
  - Registrar alterações em produtos e categorias
  - Auditar ações em tabelas sensíveis
- Tabelas de log para armazenar histórico de alterações
